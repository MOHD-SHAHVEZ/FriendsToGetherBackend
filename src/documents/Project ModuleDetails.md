# FriendsTogether - Backend Module Details

This document outlines the various modules and features that have been successfully implemented in the backend architecture of the `FriendsTogether` project.

## 1. Authentication & Security Module
Handles user identities, session security, and third-party logins.
- **Email/Password Authentication**: User registration and login with encrypted passwords (BCrypt).
- **OAuth2 Integration (Google)**: Seamless login/signup using Google accounts.
- **JWT (JSON Web Tokens)**: Stateless authentication with Access Tokens (short-lived) and Refresh Tokens (long-lived).
- **Admin Setup**: Initial bootstrapping for the Super Admin account.

## 2. User Management & Discovery
Manages user profiles and online visibility.
- **User Profiles**: View and update profile details (Name, Bio, Avatar, Location).
- **User Discovery**: Browse and discover other users on the platform.
- **Presence Tracking (Redis)**: Tracks user's real-time Online/Offline status using Redis and heartbeat mechanisms.

## 3. Social & Networking
Handles connections between users.
- **Friend System**: Send, accept, reject, and cancel friend requests.
- **Friend List Management**: View current friends and manage connections.
- **Blocking Mechanism**: Ability to block/unblock users for privacy.

## 4. Real-Time Chat (WebSocket)
Enables seamless one-to-one communication.
- **Real-Time Messaging**: STOMP over WebSockets for instant message delivery.
- **Chat History & Pagination**: Load previous chat messages with infinite scroll support.
- **Message Status**: Real-time read receipts and delivery status (Sent, Delivered, Read).
- **Typing Indicators**: Shows when the other user is typing.

## 5. Voice Rooms (Audio Calling)
Supports multi-user real-time voice communication.
- **Room Management**: Create, join, leave, and manage Voice Rooms.
- **WebRTC Signaling**: Exchange of SDP offers, answers, and ICE candidates for peer-to-peer audio connections.
- **Room Controls**: Mute/unmute microphone and track active speakers.

## 6. Wallet & Coin System
Manages the platform's virtual currency.
- **Virtual Wallet**: Each user gets a wallet initialized with a welcome bonus (50 coins).
- **Balance Tracking**: Check current coin balance.
- **Coin Deductions**: Automatically deduct coins for premium actions (e.g., creating premium rooms or sending virtual gifts).

## 7. Payments & Monetization
Handles purchasing virtual coins with real money.
- **Coin Plans**: Users can browse different coin packages (e.g., 100 Coins for ₹50).
- **Order Processing**: Create orders and initiate payment gateways.
- **Payment Webhooks**: Automated order fulfillment and wallet top-up upon successful payment via external gateways (e.g., Razorpay/Stripe).

## 8. Admin Panel (Dashboard)
Provides platform administrators with control over the system.
- **Coin Plan Management**: Admin can Create, Read, Update, and Delete (CRUD) coin packages.
- **Transaction Monitoring**: View and manage all user coin orders and transaction histories.
- **Platform Analytics**: High-level overview of users and financial data.
